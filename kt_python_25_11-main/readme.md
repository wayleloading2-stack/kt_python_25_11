# Currency Monitor

## Запуск

В корне проекта:

```sh
pip install -r requirements.txt
python -m uvicorn main:app --reload
```

Во втором терминале:

```sh
cd frontend
npm install
npm run dev
```

Открыть http://localhost:5173.

## CSV

`GET /export?interval=5` возвращает поток CSV. Интервал — целое число от 1 до 60 секунд (по умолчанию 10). Первая строка: `timestamp,base,USD,GBP,RUB`.

Скачивание продолжается до разрыва соединения. При первом подключении создаётся `exports/rates.csv`, при следующих — `exports/rates_<uuid>.csv`, чтобы выгрузки не перезаписывали друг друга. Строки сохраняются сразу. При ошибке API записывается время, EUR и пустые поля курсов.

Для проверки в терминале можно запустить:

```sh
curl -N 'http://localhost:8000/export?interval=5'
```

Остановка — Ctrl+C (в браузере отменить скачивание). Уже записанные серверные строки останутся в папке `exports`. Браузер может удалить незавершённую локальную загрузку при её отмене.

SSE продолжает использовать исходный список валют и Frankfurter v1. CSV использует Frankfurter v2, так как он поддерживает RUB. Это справочные курсы, а не биржевые котировки; опрос каждые N секунд не гарантирует изменение курса.

## Ответы на вопросы

1. StreamingResponse передаёт произвольные данные частями, а EventSourceResponse предназначен для SSE-событий в формате `text/event-stream`.
2. EventSource не подходит, поскольку он ожидает SSE-события, а CSV-эндпоинт возвращает обычные CSV-строки с типом `text/csv`.
3. При отключении клиента генератор прекращает запись, файл закрывается, а уже записанные строки остаются на сервере.
